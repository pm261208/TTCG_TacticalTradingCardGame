# MyCardGameProject

A ideia do TTCG é criar um card game ao estilo tcg, como magic, pokemon, yugioh, mas com elementos de rpgs táticos. Esse projeto ainda está em sua fase inicial de desenvolvimento atualmente o jogo só tem 3 cartas para teste dois monstros e uma magia, mas o projeto já tem vários sistemas prontos como um sistema de mana, um sistema de posicionar as cartas no campo e movelas, um sistema de ataque e pontos de vida, e um sistema de efeitos de carta trigger e ignition. Pretendo adicionar as cartas de armadilha no próximo fetch, assim como atualizar algumas funcionalidades com as cartas de magia. Se quiser testar o jogo por si próprio é só baixar o projeto no unity, ele necessita de três janelas para funcionar(1 servidor, 2 jogadores), mas já tem funcionalidade multiplayer e planejo fazer um servidor cloud para poder testar com pessoas diferentes, mas por enquanto, no menu boot, só clicar na opção servidor e nas duas outras janelas clicar na opção cliente que ele já redireciona para a mesma partida. Caso tenha alguma dúvida, e considerando que provavelmente as únicas pessoas que vão ler isso é o pessoal do CEGI, é só mandar mensagem esse é meu primeiro projeto mais ambicioso e com certeza vou ter que revisar esse código para dar uma organizada mas eu estou contente com meu progresso até aqui.
